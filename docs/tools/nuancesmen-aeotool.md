# 🟢 nuancesmen-aeotool

> Audit any website for AI citability on **67 criteria across 7 AI engines** (ChatGPT, Gemini, Perplexity, Claude, Copilot, Grok, Google AI Overviews).

Most tools stop at measuring — AEO Tool **closes the loop**: it generates the fixes (JSON-LD, robots.txt, llms.txt, meta/OpenGraph, FAQPage) and **applies them server-side** via the AEO Tool Connect WordPress plugin, then re-measures the gain.

Built for **agencies**: audit dozens of client sites in one command (`aeo_batch_audit`), get the prioritized improvement checklist (`aeo_improvements`), apply level-1 fixes (`aeo_apply`), and track AI citations (`aeo_citations`) — all from Claude.

**8 tools**: aeo_list_sites, aeo_audit, aeo_batch_audit, aeo_report, aeo_improvements, aeo_generate, aeo_apply, aeo_citations.
