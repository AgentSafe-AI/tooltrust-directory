# 🟠 emberreads-romance-books

> Search 8,000+ romance books by trope, spice level, and content warnings. Powered by community-rated data from https://www.emberreads.app.

4 tools available:
  - search_romance_books — Filter by 85+ tropes (enemies-to-lovers, grumpy-sunshine, dark-romance,
   etc.), spice level (1-5 flames), and exclude content warnings
  - get_book_details — Full book info with tropes, spice rating, and content warnings
  - list_tropes — Browse all 85+ romance tropes by category
  - get_trending_books — See what's trending on BookTok right now

 No configuration needed. Free and public.
