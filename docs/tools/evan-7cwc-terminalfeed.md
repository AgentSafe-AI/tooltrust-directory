# 🟢 evan-7cwc-terminalfeed

> Real-time world data for AI agents. 27 tools covering Bitcoin, stocks, crypto markets, prediction markets,
earthquakes, hacker news, AI infrastructure status, HuggingFace trending, Solana network health, and more. The /api/briefing tool returns a one-call world snapshot composed from 5 upstream sources, designed to fit in a single LLM context window. Premium tools (deep crypto, macro, sentiment, whales, exchange flows, DeFi TVL, stablecoin flows) accept USDC micropayments on Base via cross-redeemable credits. Free tier covers most use cases without auth.
