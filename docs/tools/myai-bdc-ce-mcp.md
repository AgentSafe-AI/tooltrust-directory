# 🟠 myai-bdc-ce-mcp

>   AI content creation for autonomous agents. Generate video scripts, images, and videos from any topic via MCP tools — pay-per-use in USDC with x402 protocol. No API keys, no signup, no subscriptions.
                                                                                                                                                                                                                
  ### Free Tools                                            
  - `get_pricing` — Live USDC pricing for all operations
  - `get_queue_status` — Queue position and estimated wait time
  - `get_content` — Full content item details
  - `get_content_status` — Lightweight status polling for pipeline progress

  ### Paid Tools (x402 USDC)
  - `create_script` — Generate AI video script from any topic
  - `create_image` — Generate image from text prompt
  - `create_video` — Produce video from completed script
  - `run_full_pipeline` — End-to-end script + video from a single prompt
