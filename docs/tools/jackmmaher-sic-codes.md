# 🟡 jackmmaher-sic-codes

> Free UK SIC code lookup, GICS/ICB cross-classification mapping, and Companies House company search.
  No API key required.

lookup_sic_code - Look up any SIC, GICS, or ICB code with full hierarchy and cross-mappings

search_sic_codes - Describe a business activity in plain English to find the right SIC code

convert_between_classifications - Convert between UK SIC 2007, GICS (MSCI), and ICB (FTSE Russell)

browse_classification_hierarchy - Browse the full SIC/GICS/ICB taxonomy trees

lookup_uk_company - Search 5.6 million Companies House records by name or number

search_uk_companies_by_industry - Find companies by classification code

Covers all 731 SIC 2007 codes, 273 GICS entries, 249 ICB entries, and 1,235 cross-classification mappings.
