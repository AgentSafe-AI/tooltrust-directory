# 🟠 xenarch-xenarch-mcp

> MCP server for USDC micropayments on Base. Pay for x402-gated content, APIs, or services — when a URL returns HTTP 402, check the payment gate, execute an on-chain USDC payment through a verified splitter contract, and receive a time-limited Bearer access token to unlock the resource. 

No API keys, no signup, fully non-custodial. Auto-generates a wallet on first run — zero config to start. Works with Claude Desktop, Cursor, Windsurf, and any Model Context Protocol client.
