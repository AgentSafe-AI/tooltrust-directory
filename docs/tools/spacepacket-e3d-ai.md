# 🟡 spacepacket-e3d-ai

> Blockchain analytics and AI agent platform for Ethereum. Query live token prices, on-chain stories, investment theses, and the E3D autonomous agent system — all backed by real-time indexed data.

**Works anonymously** at the free tier (100 req/day). Add an API key from [e3d.ai/api](https://e3d.ai/api) for higher rate limits.

**Tools include:**
- Token prices, gainers/losers across 30m / 1h / 24h / 7d / 30d
- On-chain stories and structured investment theses
- Token and wallet identity, counterparty flow analysis
- AI agent status, executions, burn history, next actions
