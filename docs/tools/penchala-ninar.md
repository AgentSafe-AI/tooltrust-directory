# 🟢 penchala-ninar

> Ninar AI runs inside Claude to audit how your brand appears (or doesn't) when customers ask AI engines for recommendations. Scan across 10 engines — ChatGPT, Gemini, Claude, Perplexity, Google AI Overviews, Google AI Mode, Meta AI, Copilot, Grok, DeepSeek — surface the content gaps that explain low rankings, then generate publish-ready FAQs, differentiators, and about copy without leaving the chat.

The free start_audit tool works with no Ninar account (5 audits per IP per hour). Other tools require a free Ninar account; some require Pro+ plan.

Auth: OAuth 2.1 + PKCE for Claude Desktop, or Bearer geo_xxx API key for Cline/Goose/scripts.
