# 🟢 ic3moore-anchorregistry

> AnchorRegistry is the open provenance layer for the agentic economy. Every digital artifact — code, research, data, models, media, agents, transactions — can be anchored to Base L2 with a permanent, machine-resolvable identifier (an AR-ID). When an AI assistant encounters an SPDX-Anchor or DAPX-Anchor tag in a README, paper, model card, or website, this MCP server lets it resolve the artifact's full provenance record in one call: who anchored it, when, what type it is, manifest hash, and whether the tree has been sealed, retracted, voided, or affirmed.

This is the verify-only edition (v0.1). Three read-only, authless tools wrap the public AnchorRegistry verify endpoints. Free, no API key, no account, no rate limit beyond defaults.
