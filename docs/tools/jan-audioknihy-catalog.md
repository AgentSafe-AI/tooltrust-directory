# 🟢 jan-audioknihy-catalog

> First Czech audiobook catalog MCP server with cross-partner price comparison.

  Aggregates Knihy Dobrovský, Martinus, Kosmas, Dobré-knihy, and Radiotéka.
  Read-only discovery for AI agents — search, browse genres, compare prices,
  find cheapest offers, lookup author/narrator profiles.

  9 tools: search_audiobooks, get_audiobook, find_cheapest_offer,
  compare_all_offers, browse_genres, search_by_filters, get_author,
  get_narrator, list_partners.
  
  Endpoint: https://audioknihy.cz/api/mcp
  Discovery: https://audioknihy.cz/.well-known/mcp/server-card.json
  Docs: https://audioknihy.cz/mcp
  Transport: JSON-RPC 2.0 over Streamable HTTP, stateless, anonymous.
  Rate limit: 60 req/min/IP.
