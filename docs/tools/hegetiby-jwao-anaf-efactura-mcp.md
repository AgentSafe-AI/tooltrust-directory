# 🟠 hegetiby-jwao-anaf-efactura-mcp

> Stop wrestling with Romania's e-Factura portal. This MCP lets Claude upload, download, validate, and track electronic invoices directly through the ANAF SPV API — no browser required.

Built for Romanian freelancers, accountants, and businesses tired of doing it manually. Works with UBL XML, handles OAuth2 auth, and speaks fluent ANAF.

Tools included:
- Upload invoices to SPV
- Download received invoices
- Check upload status
- Validate XML before sending
- List invoice history
- Generate compliant UBL XML from scratch
