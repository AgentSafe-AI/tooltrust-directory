# 🟡 mirajmahmudul57-agentdevx

> AI agent gateway for calling any API securely. Bootstrap your agent in one call, discover tools, enforce OPA policies, and inject credentials automatically.

## Features
- One-call agent bootstrap with Ed25519 identity
- Tool registry with OpenAPI ingestion
- OPA policy enforcement
- Encrypted credential vault
- Tier-based daily limits (free/starter/pro/scale)
