# 🟠 zoro-nag

> Nag MCP powers reminder scheduling that actually sends email (and supports webhooks + WhatsApp channels when enabled).

It can be used standalone or with Zoro.

## Core rule in the system (zoro welath management)

- **Orchestrator never calls Nags directly.**
- Wealth/Goals can recommend switching to Nags **only if** the user explicitly asks to schedule reminders.

## MCP server URL

`https://www.getzoro.com/api/mcp/nags`
