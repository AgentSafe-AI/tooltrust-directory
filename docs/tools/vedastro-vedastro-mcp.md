# 🟢 vedastro-vedastro-mcp

> Vedic astrology calculations powered by [VedAstro.org](https://vedastro.org). Access 6 tools covering horoscope predictions, compatibility matching, numerology, raw planet/house data, general astro data, and Ashtakvarga charts.

## Tools
- **get_horoscope_predictions** — 200+ life aspect predictions from a Vedic birth chart
- **get_match_report** — Compatibility report with 16 Kuta factors and score
- **get_numerology_prediction** — Chaldean numerology analysis by name
- **get_astrology_raw_data** — Raw planet and house data for all 9 planets & 12 houses
- **get_general_astro_data** — 24 general Vedic properties (Lagna, Moon sign, Nakshatra, etc.)
- **get_ashtakvarga_data** — Sarvashtakavarga and Bhinnashtakavarga charts

## Access
Free tier: 5 requests/minute — no API key required.  
Premium: unlimited requests with an API key from [vedastro.org/MCPServerApp.html](https://vedastro.org/MCPServerApp.html)

All calculations use the **Raman Ayanamsa** system.
