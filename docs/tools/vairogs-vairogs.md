# 🟢 vairogs-vairogs

> Latvian law search for AI agents: full-text search across all in-force Latvian statutes and regulations (likumi.lv corpus, 61k+ acts, ~1M articles, daily sync), **verbatim article text for citation**, recently-changed laws ("kas mainījies šonedēļ"), upcoming effective dates, law overviews by category, and human-verified labour-law Q&A with exact article citations. Bonus: `sudzibas_celvedis` matches a real consumer dispute (parking "fine", faulty goods, cancelled flight…) to a free complaint-letter wizard on vairogs.lv with verified recipients.

Anonymous, read-only, no API key. Latvian-first tool descriptions. Listed in the official MCP Registry as `lv.vairogs/vairogs`. Human setup guide: https://vairogs.lv/savienot

Operated by SIA Brain Club (Latvia) — first-party server for vairogs.lv. Not legal advice; verify the in-force version on likumi.lv before filing.
