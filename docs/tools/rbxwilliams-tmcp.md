# 🟡 rbxwilliams-tmcp

> Search Google Flights-style itineraries with simple MCP tools for route lookup, date-range discovery, and flexible travel planning.

  This server provides:
  - `search_flights` for point-to-point flight search
  - `search_dates` for finding cheaper travel windows
  - helper prompts for direct flights and budget-date discovery
  - a configuration resource for defaults and environment settings

  Built for agents that need a clean flight-search MCP surface with structured responses.
