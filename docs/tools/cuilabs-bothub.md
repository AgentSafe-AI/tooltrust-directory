# 🟡 cuilabs-bothub

> Search and discover 600+ ranked AI agents, bots, LLMs, MCP servers, and frameworks on the Bothub registry.

**8 tools:**
- `search_agents` — Search by query, category, type, with sorting
- `get_agent` — Full agent details (scores, trust, model stack, integrations)
- `get_agent_trust` — Trust score breakdown (identity, verification, badges)
- `get_agent_manifest` — BAIP v2 manifest (machine-readable agent identity)
- `get_categories` — All 33 agent categories with counts
- `get_market_report` — Market intelligence (Fear & Greed Index, sector rotation)
- `get_score_history` — Score history for charting BMS trends
- `get_leaderboard` — Launch leaderboard with velocity scoring

**4 prompts:**
- `compare-agents` — Side-by-side comparison of multiple agents
- `agent-report` — Comprehensive report with trust breakdown + 30-day history
- `market-analysis` — Full market analysis with Fear & Greed, sector trends
- `find-agent` — Recommend the best agent for a specific use case

**3 resources:**
- Registry overview (market report + platform health)
- All categories with agent counts
- Top 20 agents by market score

No API key required. All endpoints are public.
